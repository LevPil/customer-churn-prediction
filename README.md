# Customer Churn Prediction

Проект по предсказанию оттока клиентов телеком-компании на классическом датасете IBM Telco Customer Churn.

## Что делает проект
Загружает и анализирует данные (EDA)

Препроцессинг: обработка пропусков, кодирование категориальных признаков, масштабирование

Обучение нескольких моделей классификации (Logistic Regression, Random Forest, Gradient Boosting)

Оценка качества (Accuracy, Precision, Recall, F1, ROC-AUC, Confusion Matrix)

Анализ важности признаков

Сохранение модели


## Как запустить
```bash
pip install -r requirements.txt
python churn_prediction.py
```
